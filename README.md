# Backyard Biologist Quiz

Mobile-friendly practice quiz for the Georgia Science Olympiad 2026 Backyard Biologist event.
237 multiple-choice questions: Victoria's 100 study questions rewritten as multiple choice, 33 gap-fill
questions, and 104 researched questions (each with a source link). Practice runs in short sessions
(5/10/20/30 questions) with a live progress bar, encouragement and streaks, and a results screen listing
what to work on. Right/wrong history is tracked per device.

## Run locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
(Opening index.html directly won't work because the app fetches questions.json.)

## Publish with GitHub Pages
1. Create a GitHub repo and push this folder (`Context/` is git-ignored because it holds the source Word/PowerPoint files).
2. Repo Settings > Pages > Deploy from a branch > `main` / root.
3. Open `https://<user>.github.io/<repo>/` on your phone.

Note: GitHub Pages sites are public even if the repo is private on free plans. The site contains only quiz content.

## Questions
`questions.json` is generated by `tools/build_questions.py`: Victoria's questions come from the docx in `Context/`
(explanations are her answer-key text), gap-fill questions are in the script, and researched questions are in
`data/research_*.json` (`category, topic, question, choices[4] with the correct answer FIRST, explanation, url`).
To add more, drop another `data/research_*.json` file in that format and run `python3 tools/build_questions.py`.
Categories must match the existing seven names. Re-running the script overwrites `questions.json`.

Researched questions (`source: "research"`) were written from web sources (some pages couldn't be fetched, so a few rest on
search snippets) and have not been reviewed by Victoria yet. Please skim them before relying on them.

## Progress
Stored in the browser (localStorage). Use Progress > Export / Import to move it between devices.
