# Backyard Biologist Quiz

Mobile-friendly practice quiz for the Georgia Science Olympiad 2026 Backyard Biologist event.
133 multiple-choice questions (Victoria's 100 study questions rewritten as multiple choice, plus 33
gap-fill questions). Tracks right/wrong per device and recommends what to study next.

## Run locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
(Opening index.html directly won't work because the app fetches questions.json.)

## Publish with GitHub Pages
1. Create a GitHub repo and push this folder (`Context/` is git-ignored because it holds the source Word/PowerPoint files).
2. Repo Settings > Pages > Deploy from a branch > `main` / root.
3. Open `https://<user>.github.io/<repo>/` on your phone.

Note: GitHub Pages sites are public even if the repo is private on free plans. The site contains only quiz content.

## Questions
`questions.json` is generated by `tools/build_questions.py` from the docx in `Context/`
(explanations are Victoria's answer key text). To add questions, either append objects to `questions.json`
(`id, category, topic, question, choices[4], answerIndex, explanation, source`) or add them to the script and re-run it.
Categories must match the existing seven names. Re-running the script overwrites `questions.json`.

## Progress
Stored in the browser (localStorage). Use Progress > Export / Import to move it between devices.
